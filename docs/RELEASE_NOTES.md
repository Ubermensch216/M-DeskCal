# M-DeskCal 0.1.0-beta.1 릴리스 노트

첫 베타입니다. Windows 10/11 x64, .NET 런타임 포함(별도 설치 불필요).

## 들어 있는 기능
- **바탕화면 달력**: 5가지 표시 모드(고정 월, 변동 월, 전체 월, 고정 단일 행, 변동 단일 행), 한국 공휴일·대체공휴일·음력·24절기·기념일
- **할 일 입력**: 날짜 칸 더블클릭 인라인 입력창, 체크 완료, 취소선, 글자색/셀 색(최근 사용 색), 작업 반복, 알림(시각+다중 시점), 기념일까지 카운트다운(D-day), 이력 복원
- **날짜별 서식**: 특정 날짜 칸 셀 배경색 개별 지정, 휴일 배경색 은은한 채색 옵션
- **일정 관리**: 반복(다양한 주기 규칙), 여러 날 일정, 알림 카드와 사운드, 절전 복귀 보정
- **화면 및 메뉴**:
  - 달력 오른쪽 위 **⚙ 톱니바퀴 빠른 메뉴**
  - 체계적인 **캘린더 설정 창** (캘린더, 셀, 글꼴 및 색상, 메모, 고급, AI, 제품 정보 7개 탭)
  - **빠른 입력** (`Ctrl+Alt+Q`): 한 문장으로 일정 추가·질문(날짜·시각·반복·알림을 규칙으로 즉시 해석, AI 는 선택·기본 꺼짐·로컬 서버만 기본 허용, 확인 후에만 추가, 겹치는 일정 경고, 맞음/틀림 기록, 마지막 추가 되돌리기)
  - **아침 브리핑·지난 7일 돌아보기**(자동 표시 선택·기본 꺼짐, AI 불필요, AI 문장 다듬기는 검증 후에만 표시), **빈 시간 묻기**, **의미 검색**(임베딩 모델 선택 시, 검색 창)
  - **텍스트에서 일정 추출**: 공지·메일·대화를 붙여넣어 날짜가 있는 문장을 일정/할 일로 일괄 추가(원문 표시, 기준일, 중복·겹침 표시, 추가 전 자동 백업, 한 번에 되돌리기)
  - 8방향 리사이즈 핸들과 점선 테두리를 지원하는 **위치/크기 조정** 모드
  - 5개 그룹으로 정돈된 **트레이 메뉴**, 전역 단축키 5종, Windows 시작 시 자동 실행
- **부가 기능**: 검색(부분 일치/필터), 디데이 카드, 메모, 시간표(바탕화면 위젯), 배경 사진 폴더 순환, 현재 달 인쇄
- **가져오기/내보내기**: JSON(전체 백업·복원) · CSV · ICS · Excel(.xlsx, 보기 전용 서식 달력 시트)
- **콘텐츠 잠금**: 비밀번호 기반 화면 가리기(민감한 내용 숨김)
- **외부 캘린더 동기화**: CalDAV(Nextcloud, Synology, iCloud 등, 기본 받기 전용 / 안전 양방향)
- **AI 연동 (MCP)**: 로컬 MCP 서버 내장(`deskcal-mcp.exe`), 모든 변경 요청은 사용자 승인 대기열을 거쳐 반영. 도구 19개(일정·할 일·디데이·메모·시간표 조회, 빈 시간·음력·공휴일 계산, 하루 요약, 디데이·메모 추가 요청)와 준비된 프롬프트 3종(아침 브리핑·앞으로 7일·지난 주 돌아보기)
- **문서화**: 화면 스크린샷과 설정법이 포함된 `README.md` 사용자 매뉴얼 및 상세 `사용자 가이드.md`

## 설치
`README.md` 또는 `사용자 가이드.md` 의 "설치와 제거" 참고. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다(*추가 정보 → 실행*).
무결성 확인: 함께 제공되는 `.sha256` 파일의 값과 zip 의 SHA-256 이 같은지 비교하세요.

## 알려진 문제·한계
`사용자 가이드.md` 10장 참고. 특히:
- **직접 확인되지 않은 부분**: 실제 iCloud/Nextcloud/Google 서버, 실제 AI 클라이언트, 프린터 출력, 다중 모니터·고배율, 재부팅 후 자동 실행, 7일 이상 연속 실행 안정성.
- Google Calendar·Microsoft Graph 동기화는 포함되지 않았습니다(CalDAV 표준 서버 지원).
- 콘텐츠 잠금은 화면 표시 가림 기능이며 데이터베이스 암호화가 아닙니다.
- 바탕화면 달력은 다른 앱 창보다는 아래, 바탕화면 아이콘보다는 위에 위치하므로 아이콘이 없는 영역에 배치하여 사용하는 것을 권장합니다.

## 데이터 호환
데이터베이스 스키마는 v8 입니다(할 일의 완료·이월 기록 `item_activity`, 의미 검색 색인 `embeddings` 추가). 새 버전은 이전 데이터를 자동으로 올립니다(되돌리기 불가 — 설치 전 JSON 백업 권장). 이 베타보다 새로운 데이터베이스는 열지 않고 오류로 알립니다.
