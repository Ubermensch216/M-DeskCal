# M-DeskCal 0.1.0-beta.1 릴리스 노트 (2026-11-16)

Windows 바탕화면 달력 **M-DeskCal** 의 첫 베타 버전입니다. 다른 프로그램의 코드·리소스를 쓰지 않고 새로 만들었습니다.

## 포함된 기능
- **바탕화면 달력**: 다른 창 뒤에 머무는 반투명 달력. 표시 모드 5종(고정 월 / 변동 월 / 전체 월 / 고정 단일 행 / 변동 단일 행), 주 시작 요일, 주차 번호, 그림자, 글꼴·글자 크기·색·배경 투명도, 위치·크기 조정, **⚙ 빠른 메뉴**(`일정 · 도구` / `화면 표시` / `설정` 3개 그룹과 플랫 벡터 아이콘) 및 **캘린더 설정 창**(3개 구획 · 8개 탭)
- **할 일(날짜 칸)**: 더블클릭 편집, **옵션 버튼**(완료·글자/셀 색·작업 반복·알림·D-day 연결), 완료 체크·완료 효과음, 글자색·배경색(최근 사용 색 보존), 변경 이력 보기·복원
- **한국 달력**: 음력(1900~2050), 24절기(천문 계산), 대한민국 공휴일·대체공휴일·기념일, `holidays.json` 사용자 보정
- **일정**: 시작/종료 시각·종일·다일, 반복 규칙(매일/매주/매월/매년/평일/월말/분기말/법정 근무일/음력 매년/에빙하우스), "이 일정만 / 이후 모두 / 전체" 부분 수정·삭제, 자체 알림 팝업 카드(확인 / 10분 뒤 다시, 놓친 알림 표시)
- **스마트 도구(규칙 + 선택형 로컬 AI)**: 모던 카드형 UI로 개편된 **새 일정**, **캘린더 채팅**(`Ctrl+Alt+Shift+C` 또는 달력 상단 `✨ 캘린더 채팅` 더블클릭 — 자연어 일정 등록·기간/빈 시간 조회·키워드/상세 필터/의미 검색 및 변경 이력 복원 통합), **텍스트·이미지(OCR)에서 일정 추출**, **복습 계획 만들기**(공부한 날부터 / 시험일 앞으로), **미완료 정리**(오늘·다음 업무일·여유 있는 날로 나누기), **오늘 브리핑 · 지난 7일 돌아보기**
- **디데이(카운트다운)**: 시험·생일(만 나이)·만난 날(N일째 + 다음 주년)·명절(음력 지원), 달력 하단 줄 + 바탕화면 카드
- **메모·시간표·배경 사진**: 메모(색·이력·되살리기), 시간표(교시 자동 생성·바탕화면 위젯·현재 교시 강조), 폴더 사진 배경 순환
- **콘텐츠 잠금**(`Ctrl+Alt+L`): 달력·위젯·알림에서 개인 내용 숨김, 비밀번호(PBKDF2-SHA256) 보호
- **가져오기 / 내보내기 / 인쇄**: JSON(백업·복원), CSV(엑셀, UTF-8 BOM / CP949), ICS(다른 달력과 교환), Excel(`.xlsx`, 목록 + 월별 달력 시트), 현재 달 A4 가로 인쇄
- **동기화(Git · CalDAV) 및 외부 AI(MCP)**: 내 Git 저장소를 통한 여러 컴퓨터 간 전체 달력 자동 병합 동기화(`캘린더 설정 → 동기화` 탭, 진행·성공·오류 상태 색상 표시), CalDAV(iCloud/Nextcloud 등, 받기 전용 기본 / 양방향 선택), 로컬 AI 에이전트 연동(`deskcal-mcp.exe`, 조회·빈 시간·한국 달력 계산 도구 + 변경 요청 승인 대기·감사 기록)
- **트레이·전역 단축키·자동 실행**: 오늘 날짜를 그리는 트레이 아이콘, 전역 단축키(`Ctrl+Alt+D/H/E/F/L` 및 `Ctrl+Alt+Shift+C`), Windows 시작 시 자동 실행

## 요구 사항
- Windows 10 (버전 1903, 빌드 19041) 이상 또는 Windows 11, **64비트(x64)**
- 별도 런타임 설치 불필요 (자체 포함 경량 패키지 — 압축 파일 약 **26.5 MB**, 설치 후 약 **67.5 MB**)

## 설치·업데이트·제거
- **설치**: zip 을 모두 푼 뒤 `Install.cmd` 더블클릭 → `%LocalAppData%\Programs\M-DeskCal` 에 설치되고 바탕화면과 시작 메뉴에 바로 가기가 생깁니다(관리자 권한 불필요).
- **업데이트**: 새 zip 으로 `Install.cmd` 를 다시 실행하면 덮어씁니다. 일정·설정은 `%AppData%\DeskCal` 에 따로 있어 유지됩니다.
- **제거**: *설정 → 앱 → 설치된 앱 → M-DeskCal → 제거* (또는 `Uninstall.cmd`). 데이터를 함께 지울지 물어봅니다.

## 알려진 한계 (베타)
- 코드 서명이 없어 첫 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다(*추가 정보 → 실행*).
- 자동 업데이트 기능은 없습니다(새 zip 으로 업데이트).
- 플로팅 버튼·바탕화면 실시간 캡처 배경은 포함되지 않습니다.
- 반복 규칙 "매월 31일" 은 짧은 달에 말일(28·29·30일)로 당겨져 표시됩니다.
- 콘텐츠 잠금은 화면 표시를 가리는 기능이며 데이터베이스 파일(`deskcal.db`) 자체를 암호화하지는 않습니다.
- 다중 모니터·고배율 전환, 7일 이상 연속 실행은 사용자 환경에서의 추가 확인이 필요합니다.
