# M-DeskCal 0.1.0-beta.1 릴리스 노트

첫 베타입니다. Windows 10/11 x64, .NET 런타임 포함(별도 설치 불필요).

## 들어 있는 기능
- 바탕화면 달력(5가지 표시 모드, 한국 공휴일·음력·24절기), 날짜 칸 더블클릭 입력, 할 일 완료·색·알림·이력 복원
- 할 일 입력창 옵션 버튼: 완료 표시 · 글자색/셀 색(최근 사용 색) · 작업 반복 · 알림(시각+여러 시점) · 기념일까지 카운트다운
- 일정(반복·알림·여러 날), 알림 카드와 절전 복귀 보정
- 트레이 메뉴, 전역 단축키, 자동 실행, 단일 실행
- 검색, 디데이 카드, 메모, 시간표(바탕화면 위젯), 배경 사진 순환, 인쇄
- 가져오기/내보내기: JSON · CSV · ICS · Excel(내보내기만)
- 콘텐츠 잠금(화면 가리기)
- 외부 캘린더 동기화(CalDAV, 기본 받기 전용) · 로컬 MCP 서버(변경은 승인 후 반영)

## 설치
`사용자 가이드.md` 의 "설치와 제거" 참고. 코드 서명이 없어 SmartScreen 경고가 나옵니다.
무결성 확인: 함께 제공되는 `.sha256` 파일의 값과 zip 의 SHA-256 이 같은지 비교하세요.

## 알려진 문제·한계
사용자 가이드 9장 참고. 특히:
- **직접 확인되지 않은 부분**: 실제 iCloud/Nextcloud/Google 서버, 실제 AI 클라이언트, 프린터 출력, 다중 모니터·고배율, 재부팅 후 자동 실행, 7일 이상 연속 실행 안정성.
- Google Calendar·Microsoft Graph 동기화는 포함되지 않았습니다.
- 콘텐츠 잠금은 데이터베이스 암호화가 아닙니다.

## 데이터 호환
데이터베이스 스키마는 v6 입니다. 새 버전은 이전 데이터를 자동으로 올립니다(되돌리기 불가 — 설치 전 JSON 백업 권장). 이 베타보다 새로운 데이터베이스는 열지 않고 오류로 알립니다.
